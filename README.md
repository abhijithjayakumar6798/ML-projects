# Machine Learning Projects

A collection of machine learning projects and educational analysis notebooks.

## Included Notebooks & Projects

1. **`Lottery_Prediction_Analysis.ipynb`**
   - **Topic:** Statistical foundations of randomness, I.I.D. variables, and Machine Learning on stochastic sequences.
   - **Content:** Demonstrates through statistical hypothesis testing (Chi-Square goodness of fit, autocorrelation) and machine learning benchmarks (Logistic Regression, Random Forest, Deep Neural Networks) why ML models cannot outperform theoretical random baselines on independent lottery draws.
   - **Target Audience:** AI/ML students and engineers exploring signal vs. noise, overfitting, and probability theory.

2. **`Diabetes_prediction.ipynb`**
   - **Topic:** Binary classification for diabetes prediction using machine learning models and standard scaling.

3. **`Heart.ipynb`**
   - **Topic:** Heart disease risk prediction classification pipeline.

4. **`Rock_vs_Mine.ipynb`**
   - **Topic:** Sonar data analysis and binary classification for distinguishing rocks vs. naval mines.

5. **`Spam_mail_detection.ipynb`**
   - **Topic:** Text classification and NLP pipeline for email spam detection.
